# `bbd`

BarterBackup daemon

## Usage

```text
Usage: bbd [OPTIONS]
```

## Options

- `--local-addr <LOCAL_ADDR>`: local_addr is the local loopback address for the CLI gRPC service (env: `BBD_LOCAL_ADDR`)
- `--data-dir <DATA_DIR>`: data_dir is the base directory for all daemon state (env: `BBD_DATA_DIR`)
- `--arti-config <ARTI_CONFIG>`: arti_config is one optional Arti TOML file for custom test networks (env: `BBD_ARTI_CONFIG`)
